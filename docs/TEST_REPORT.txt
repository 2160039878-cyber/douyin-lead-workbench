本次改动
- 内置 Streamable HTTP MCP 端点 http://127.0.0.1:19423/mcp，默认关闭，在设置中开启。
- 独立加密令牌，与浏览器配对码分离；支持关闭、复制及重置令牌。
- 10 个工具：get_status、list_records、create_task、start_task、control_task、generate_draft、edit_draft、open_review、execute_approved、get_daily_report。
- MCP 不提供批准草稿、修改发送核实结果、读取密钥或任意脚本/SQL/文件执行工具。
- 修复保存后再次取消编辑可能误保存的问题；修复分块 HTTP 请求跨 UTF-8 字节边界时可能损坏中文的问题。

重要边界
- 上述 MCP 是实际 SDK/HTTP 连接，采集与发送流程中的抖音数据和回执是隔离模拟，不代表真实平台链路已验证。
- 未登录真实抖音账号、未发送真实评论或私信、未调用真实付费模型 API；仍按用户选择留待后续验收。
- 私信缺少可靠回执时进入待核实并暂停，不自动当作成功或重发。
- 安装包未代码签名。未修改 Codex 或其他 AI 客户端的全局 MCP 配置。
- 本次为本机测试，未操作远程服务器；0.1.0 交付文件保留，可回退。

开始使用
运行 0.1.1 安装包或便携版，在 设置 → MCP接口 启用。MCP 客户端使用上述 URL，并配置 Authorization: Bearer 后接软件内复制的独立 MCP 令牌。不要把真实令牌发到聊天或日志中。详细工具与接入说明见 MCP接入说明.md。
