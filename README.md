# 抖音线索工作台 0.1.1

Windows x64、本地数据、单账号、人工审核后执行。不是抖音官方软件。

0.1.1 新增本机 MCP 接口，支持 AI 客户端读取状态和记录、控制采集、准备草稿与执行已批准队列。默认关闭，在“设置 → MCP 接口”启用。接入方式与工具列表见 `MCP.md`。不自动修改任何 AI 客户端的全局配置。

## 当前交付边界

已实现本地搜索任务、关键词规则、分页调度、草稿、审核队列、发送去重、操作记录、每日备注及导出。模型可选，未配置时使用固定话术。

**真实抖音登录、搜索、回复和私信尚未通过用户账号验收。** 本地自动测试使用隔离数据和模拟传输，不代表平台链路已跑通。上游网页接口可能随抖音变化而失效。

**私信确认限制：** 上游协议解码没有可靠的发送确认字段。因此，私信请求结束后默认标记“待核实”，并暂停余下队列。请在抖音核实后填写依据，人工标记“已发送”或“未发送”。不能将 HTTP 成功或无异常当作送达。

## 安装与首次连接

1. 运行 Windows 安装包，或运行便携版。软件未进行代码签名，请自行确认文件来源。
2. 在 Chrome 或 Edge 安装 Tampermonkey，并按扩展提示允许用户脚本运行。
3. 打开工作台“设置”，点击“安装配套脚本”，在 Tampermonkey 页面确认安装。如果浏览器显示源码，在 Tampermonkey 的新建脚本编辑器中粘贴该完整源码并保存。
4. 点击“打开抖音”，正常扫码或登录，只保留一个用于工作台的抖音标签页。
5. 在工作台点击“复制配对码”；在浏览器扩展的脚本菜单选择“连接工作台：输入配对码”，粘贴并确认。配对码不要分享，剪贴板中的配对码会在 60 秒后清除。
6. 返回工作台，等待“浏览器已连接”。未连接时先刷新抖音标签页，检查是否登录、脚本是否启用，以及本机端口 19423 是否被其他程序占用。

配套脚本只连接本机 127.0.0.1:19423。用户关闭浏览器、切换账号、验证提示或电脑休眠都会影响任务，软件会暂停或保留待核实结果。安装包不包含登录信息。

## 日常操作

1. “搜索采集”：视频搜索词决定查找范围；评论匹配词决定保留内容。每行一个词或逗号分隔。排除词优先。创建任务后点击开始。
2. 软件顺序打开视频，等待页面加载，再按游标读取评论。达到上限、重复页面或无下一页时停止相应采集。可随时暂停，未完成的发送请求不会被取消后重发。
3. “潜客列表”：查看原评论、关键词和来源视频；标记保留、排除或已跟进，填写备注。
4. 使用模板或 AI 生成回复/私信草稿。AI 只提供文案，不能自行发送。匿名或缺少可靠用户标识的评论不能创建私信。
5. “审核发送”：编辑文案，勾选草稿，批准弹窗中具体的目标与内容。批准不等于已发送；再次选中已批准记录并点击执行才会发送。
6. 单批最多 10 条；默认间隔 60 秒。修改文案撤销原审核。相同账号对相同评论的回复、对相同用户的私信默认不重复；成功或待核实项不能再次自动执行。
7. “操作日志”：查询记录，导出完整发送明细 CSV 或按北京时间生成的每日文本。日期筛选的开始日期也是每日备注和导出的日期。

列表界面最多展示最近 5000 条记录；CSV、每日记录导出和工作台统计读取完整数据库。工作台支持日期范围统计，不估计成交效果。

## 模型 API

填写 HTTPS 基础地址（包含服务要求的 `/v1`，不包含 `/chat/completions`）、模型名称、API Key。服务需兼容 OpenAI Chat Completions 格式。

生成时只发送必要的视频标题、评论正文和业务话术资料，不发送 Cookie、浏览器会话或用户标识。原评论可能包含个人信息，使用前请确认所选模型服务适合处理这些内容。模型费用由所选服务计费。

更换 API 地址时需要重新输入密钥或清除旧密钥，避免误发凭据。API 不可用时可以直接使用模板，或编辑现有草稿。

## 数据与备份

在“设置 → 打开数据目录”查看数据库和加密凭据。数据位于当前 Windows 用户的应用数据目录，独立于安装文件。

API Key 和配对码用 Windows 系统加密保存，不导出到日志。数据库备份只包含业务数据，不含加密凭据；请通过“保存数据库备份”生成一个新文件。备份使用 SQLite 一致性快照。

恢复时先退出软件，将原数据目录重命名为备份目录，再创建原名称的空目录，把已验证的数据库备份复制为新目录下的 `workbench.db`。不要复制旧的 `-wal` 或 `-shm` 文件，也不要在应用运行时替换数据库。恢复后重新配对浏览器并配置模型密钥。数据库含客户来源及评论信息，应妥善保管，不要把自己的数据目录打包给别人。

## 开发与来源

应用使用 Electron、Node.js 标准库 SQLite、原生 HTML/CSS/JavaScript。未启动远程服务器。

浏览器接口选自 MIT 项目 https://github.com/Yht20927/douyin-cli ，固定提交 `4073159bea585de6d33a4747a475669440737932`。许可证见 `vendor/LICENSE`，来源及改动见 `vendor/ORIGIN.txt`。未合入非商业许可项目代码。

主要修改：固定操作协议替代通用 eval 网络入口、连接配对、单账号检查、审核状态机、发送不自动重试、64 位会话 ID 编码修复、移除随机发布元数据及原始响应日志。浏览器 API 作为固定打包代码加载，不接受网络下发的 JavaScript。

Node.js 24 或更新版本；源码仓库根目录即应用目录，打包产物位于 `dist/`：

```powershell
npm ci
npm test
npm start
npm run build
```

源码包已包含生成的浏览器 API 和脚本。仅需重新提取上游时，将此目录放入上述固定提交的仓库下，命名为 `desktop`，再运行 `npm run vendor`。

`test/smoke.cjs` 是真实 Electron 的本地界面冒烟测试入口，使用独立临时数据，不连接抖音。不会执行真实评论或私信。测试结果见 [测试报告](docs/TEST_REPORT.txt)。
